Privacy Policy for Levi's Notes Mirror

Effective date: [LAUNCH DATE]

Updated: app name changed; no change to data practices.

Levi's Notes Mirror ("the app") is a personal tool built and used only by its owner, Levi Eck. This policy explains what data the app uses and how.

What data the app accesses

The app requests only Google's drive.file permission. With it, the app can see and change only the files and folders that the app itself creates in the owner's Google Drive. It cannot read, list, or change any other file in Google Drive, and it does not access Gmail, contacts, calendar, or any other Google data.

Why

The app copies the owner's own notes from his OneDrive into a folder in his own Google Drive, so that the copy stays up to date. That is its only purpose.

Sharing, selling, and ads

  • The app does not sell, rent, or share any data with anyone.
  • The app shows no ads and uses no data for advertising.
  • The app has no other users. It is not offered to the public.

How credentials are stored

The Google sign-in token the app uses is stored encrypted in the hosting provider's secret storage. It is not stored in source code or shared with anyone.

How to revoke access

You can remove the app's access at any time at https://myaccount.google.com/permissions. Select Levi's Notes Mirror and choose to remove access.

Google API Services User Data Policy

Levi's Notes Mirror's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Specifically, data obtained through Google APIs is used only to provide the mirroring feature described above. It is not transferred to others except as needed to provide that feature, to comply with law, or as part of a merger or acquisition; it is not used for advertising; it is not used to train AI or machine learning models; and no person reads it except with the owner's consent, for security purposes, or to comply with law.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
